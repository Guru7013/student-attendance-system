# Student Attendance System

A Python desktop application built with CustomTkinter and SQLite for managing student attendance and generating reports.

## Features
- Track student attendance easily
- Store records using SQLite database (`student_system.db`)
- Export and view analytics reports (`student_analytics_report.csv`)
